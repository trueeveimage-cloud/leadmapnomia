# Support SOPs

## False Positive

Apologize, acknowledge the official source, explain what changed technically, tag the pattern for suppression, and review the extraction rule.

## Missing Update

Ask for the source URL. Check whether it is in the monitored set, whether the latest run succeeded, and whether severity rules suppressed the change. Add the source if it is in scope.

## Billing

Use Stripe status as truth. Send the billing portal link and explain next invoice, grace period, or cancellation state.

## Confidence Question

Provide the official source link, diff excerpt, confidence score, and review history. Do not overstate certainty.

## Legal Or Compliance Interpretation

State that the alert is informational, point to the official source, and avoid legal advice.
